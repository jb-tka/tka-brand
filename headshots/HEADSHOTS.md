# TKA Staff Headshot Directory

Official headshots, names, and titles for all The King's Academy (TKA) faculty and staff,
sourced from the public staff directory at https://www.tka.net/about/meet-the-team.

**296 people.** Photos are hosted in the public `jb-tka/tka-brand` GitHub repo.

## How to use these photos

Every photo URL follows this pattern (base URL + the File value from the table below):

```
https://raw.githubusercontent.com/jb-tka/tka-brand/main/headshots/<file>
```

For example, Alexandra Adams → `https://raw.githubusercontent.com/jb-tka/tka-brand/main/headshots/alexandra-adams.jpg`

To place a headshot in an HTML agenda email or page (portrait 4:5, max 600px tall, ~40KB):

```html
<img src="https://raw.githubusercontent.com/jb-tka/tka-brand/main/headshots/alexandra-adams.jpg"
     alt="Alexandra Adams" width="120" style="border-radius: 8px;">
```

Typical meeting-prep layout: photo at 100–140px wide with the person's name in bold
(Royal Blue #003580) and their title beneath. Note: Outlook may hide remote images until
the reader clicks "Download pictures" — normal for internal mail.
